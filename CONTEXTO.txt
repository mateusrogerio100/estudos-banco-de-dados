4. CONTEÚDO DO PROFESSOR JÁ RECEBIDO
---------------------------------------------------------------------
- Aula 06: projeto conceitual/lógico/físico; SQL = DDL + DML;
  CREATE DATABASE (OWNER, TEMPLATE, ENCODING, TABLESPACE, CONNECTION LIMIT);
  DROP DATABASE; tipos (smallint, integer, bigint, numeric, real, serial,
  varchar x char x text, date, time, timestamp, interval);
  CREATE TABLE ([NOT] NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY ... REFERENCES);
  ALTER TABLE (ADD/DROP COLUMN, ADD/DROP CONSTRAINT); DROP TABLE
  (não remove tabela referenciada por outra); regras: atributo chave não
  pode ser removido, coluna NOT NULL não pode ser adicionada em tabela com
  dados; DML: INSERT, UPDATE, DELETE (cuidado: sem WHERE afeta TUDO), SELECT.
- Aula 07: modelo FUNCIONARIO / CARGO / TELEFONE / DEPENDENTE +
  tabelas associativas (PK composta + 2 FKs); CREATE SEQUENCE + NEXTVAL;
  ordem de inserção (cargo antes de funcionário); SELECT, *, WHERE, AND,
  <> / !=; ORDER BY ASC/DESC; JOIN ... ON; join pelo WHERE (FROM a, b);
  AS (alias de coluna e de tabela).
- Aula 07 parte II: INNER JOIN, LEFT OUTER, RIGHT OUTER, FULL OUTER,
  NATURAL JOIN, USING (...), CROSS JOIN (produto cartesiano), UNION JOIN
  (conceito). Exemplo EMPRESTIMO x CLIENTE.
- Exercício 08: resolvido em professor/exercicio08.sql e rodado no
  schema exercicio_relacionamento (conferido, tudo certo).
  Decisão: FK de pedido.id_cliente ficou comentada porque o PDF insere
